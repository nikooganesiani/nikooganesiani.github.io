# Анимированные иконки ENKA

## Источники для следующих изменений

По просьбе владельца проекта новые интерфейсные иконки выбираем из этих библиотек:

| Библиотека | Каталог | Исходники / документация | Лицензия |
| --- | --- | --- | --- |
| useAnimations | https://useanimations.com/ | https://useanimations.com/icons.json — каталог с адресами SVG и анимаций; https://useanimations.com/documentation.md | MIT: https://useanimations.com/licencing-and-terms |
| Heroicons Animated | https://www.heroicons-animated.com/ | https://github.com/Aniket-508/heroicons-animated ; реестр: `https://www.heroicons-animated.com/r/<name>.json` | MIT: https://github.com/Aniket-508/heroicons-animated/blob/main/LICENSE |
| Lucide Animated | https://lucide-animated.com/ | https://lucide-animated.com/llms.txt ; https://github.com/pqoqubbw/icons ; реестр: `https://lucide-animated.com/r/<name>.json` | MIT: https://github.com/pqoqubbw/icons/blob/main/LICENSE |

Источники проверены 18 ноября 2026 года. SVG-геометрия и движения адаптированы для статического Jekyll-сайта через Web Animations API. React, Motion и Lottie для этого набора не загружаются. Это локальная адаптация компонентов библиотек: продолжительность, амплитуда и триггеры подобраны для магазина.

Используем Lucide Animated как основу; недостающие аналоги берём из Heroicons Animated. Facebook взят из useAnimations. Значок чата ведёт на существующую ссылку WhatsApp. Полное соответствие локального имени и адреса исходника: [_data/icon_sources.json](_data/icon_sources.json).

## Поведение

- `auto`: короткое движение при наведении на кнопку или ссылку, при получении фокуса с клавиатуры и при активации. Информационные значки реагируют на наведение на сам значок.
- Сердце, покупка, меню, каталог и переключение вида также реагируют на наведение и фокус, а при нажатии проигрываются повторно. В избранном сохраняется заливка активного сердца. Режим только по нажатию используется лишь при явном `trigger='click'`.
- `click`: только активация кнопки/ссылки, включая Enter/Space и касание на телефоне.
- `enter`: однократное появление, например прорисовка галочки в подтверждении заказа. Повторяется при следующем открытии.
- `loop`: только для процесса или состояния: ожидание ответа в формах, проверка заказа и грузовик у статуса «В пути». Цикл останавливается, когда значок скрыт, вышел за пределы экрана, удалён или вкладка неактивна.
- `prefers-reduced-motion: reduce` отключает эти анимации, в том числе при изменении настройки в уже открытой вкладке. Смысл статических значков и состояние кнопок сохраняются. Без JavaScript серверные SVG остаются видимыми.

Флаги языков, логотип, favicon, товарные изображения, фоновые узоры и маски фотографий — графические материалы, а не интерфейсные иконки. Уже анимированные иллюстрация переключателя темы и загрузчик фотопоиска сохранены со своими лицензиями.

## Где редактировать

- `_data/icons.json` — единый набор SVG-элементов без внешней обёртки `<svg>`.
- `_includes/icons.html` — обёртка Jekyll, размер, цвет, доступность и триггер.
- `assets/js/global/icon-markup.js` — автоматически сгенерированный рендерер для JS-карточек, избранного, заказов и рекомендаций. Не редактировать вручную.
- `assets/js/global/animated-icons.js` — движения отдельных частей значка и делегированные события. Внешний SVG не трансформируется: поворот стрелки раскрытого блока и другие состояния родительского элемента продолжают работать.
- `_data/catalog.yml`, `admin/public/store-icons.json` — резервные иконки категорий; при изменении геометрии категории обновить и их. `admin/public/store-engine.js` содержит анимированный резервный значок для новой категории.
- `assets/licenses/` — распространяемые уведомления авторских прав: MIT для анимированных библиотек и Heroicons, ISC/MIT для Lucide/Feather. Лицензии позволяют коммерческое использование и модификацию; уведомления сохраняем в проекте и сборке.

Добавление в шаблон:

```liquid
{% include icons.html name='phone' size=20 %}
{% include icons.html name='success' size=30 trigger='enter' %}
{% include icons.html name='loader' size=18 trigger='loop' %}
```

Добавление в динамическую разметку:

```js
window.EnkaIcons.render('heart', 18, 'click');
```

После изменения `_data/icons.json` выполнить `node scripts/build-icons.cjs`. Основная генерация сайта вызывает его автоматически. У нового значка должны быть источник, лицензия и подходящее движение в контроллере; не добавлять новый статический SVG отдельно в карточку или шаблон.

Сами SVG декоративные (`aria-hidden="true"`), названия действий находятся на кнопках и ссылках. Сохранять подписи, `aria-pressed`, `aria-expanded` и текущую логику форм при любых следующих заменах.
