# Проверка производительности — 18 ноября 2026

Изменения подготовлены в локальном checkout. Публикация в рабочий сайт не выполнялась.

## Изменения

- `optimize-site.cjs` запускается после Jekyll в `pnpm build` и GitHub Actions. Он объединяет соседние классические defer-скрипты, сохраняет их порядок и глобальные функции для обработчиков в HTML, минифицирует код и создаёт CSS/JS с хешами содержимого. Стабильные группы переиспользуются между страницами. Аналитика с DOM-атрибутами и локальные подмены сервисов сохраняют отдельные подключения.
- Контроллеры темы и переходов встраиваются в head при упаковке. Настройки магазина выносятся в общий кешируемый файл. `check:site` проверяет целостность файлов и inline-контроллеров по манифесту, затем исходную последовательность подключений.
- В Cloudflare Pages `_headers` задаёт immutable-кеш для файлов с хешами. GitHub Pages использует собственную политику кеширования; уникальные имена ресурсов сохраняют корректность обновлений и там.
- KA не скачивает словарь переводов. RU/EN предзагружают только выбранный словарь; его имя меняется при изменении содержимого. Пользовательские строки магазина, переводы динамических элементов и защищённые данные товаров сохраняются.
- Обработка ответа каталога выполняется один раз для всех потребителей. Повторное чтение кеша не пересчитывает цены и не пересоздаёт витрину. События изменения цен и расписание акций продолжают работать.
- Неизменившиеся баннеры не пересоздаются. Скрытые категории меню строятся при открытии; готовый HTML сохраняет начальную панель.
- Дополнительные фотографии карточки получают src при выборе фотографии. Первая фотография остаётся доступна браузеру сразу. Галерея товара и изображения для увеличения сохранены.
- Избранное читает textContent вместо innerText; обновления после изменений DOM объединяются. Измерения шапки и нижнего меню используют ResizeObserver и не записывают неизменившиеся размеры в корневые CSS-переменные.
- Фон загрузчика появляется за 100 мс. Убрана минимальная длительность 460 мс. После DOMContentLoaded подготовка содержимого может удерживать покрытие до 450 мс вместо 1800 мс; видимые карточки и шрифт больше не задерживают раскрытие. Таймер не является жёстким сроком при занятом главном потоке. Проверка актуальной цены и доступности товара по-прежнему блокирует отправку до ответа каталога. Native view-transition snapshots отключены, чтобы не заменять живую анимацию статическим снимком.
- В favicon.svg удалены лишние метаданные и заново сжат встроенный PNG: 164 549 → 75 198 байт. Декодированные пиксели до и после совпадают побайтно.

## Условия измерений

Chrome, чистый контекст для каждой страницы, viewport 1440×900, CPU throttling ×4, сеть 1,6 Мбит/с на загрузку, 0,75 Мбит/с на отдачу, задержка 150 мс. Локальный сервер отдаёт HTML/CSS/JS/SVG с gzip. HTTP-кеш отключён через no-store одинаково для обеих версий; преимущества повторного использования кеша в эти цифры не входят. Каталог, заказ и отслеживание заменены локальными сервисами; реальные заказы не отправлялись.

Внешний CDN изображений недоступен в этой среде (`ERR_NETWORK_ACCESS_DENIED`). Поэтому результаты показывают работу фронтенда и локальных ресурсов, а не полное время загрузки реального сайта с фотографиями, CDN и production API. LCP и полную визуальную готовность следует повторно измерить после публикации с доступными фотографиями. Измерение DCL не является измерением готовности всех изображений.

FCP и суммарное время длинных задач не улучшились устойчиво на всех страницах. Объединение ресурсов сокращает сетевое ожидание и время инициализации, но не гарантирует постоянные 60 FPS на любом устройстве. Отчёт не является обещанием Lighthouse 100 или измерением пользовательских Core Web Vitals.

## Проверки

- 199 автоматических тестов storefront/admin, включая глобальную область видимости и порядок исполнения production-бандлов, целостность ресурсов, кеш каталога и раздельную загрузку переводов.
- `check:site`: все 90 страниц, включая 82 страницы товаров; локальные ссылки, формы, SEO-метаданные, JSON-LD, общие компоненты и подключения.
- `check:translations`: 90 страниц и 76 записей переводов товаров.
- Браузер: выбор фотографий в карточках, избранное, все категории модального меню, поиск, сортировка, галерея и увеличение, ошибка и успех локального заказа, RU/EN/KA, тема и переходы, мобильная компоновка 390 px, работа каталога и товара без JavaScript. Ошибок выполнения JavaScript не обнаружено.
- Переходы: leaving → arriving → revealing → idle и возврат через историю; автоматические тесты также покрывают недоступное хранилище, отменённую навигацию, reduced motion и быстрый следующий переход.

Для дальнейшего сравнения сохранены исходная сборка, JSON-замеры, скрипты браузерных проверок и снимки в игнорируемой папке `.local/performance/`. Обычная сборка и публикация не зависят от этой папки или установленного там инструментария.

## Сборка

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm check:site
pnpm check:translations
```

При отдельном вызове Jekyll обязательно выполнить `pnpm build:assets` после него. Повторная упаковка уже оптимизированного результата безопасна; после изменения исходников сначала требуется новая Jekyll-сборка.
