# Как редактировать переводы ENKA

На сайте три основных языка: грузинский (оригинал), русский и английский. RU/EN используют сохранённые переводы из файлов сайта и опубликованные переводы товаров из админки. Google загружается только для остальных языков. Переключатели вверху и внизу страницы сохраняют один и тот же выбор языка.

## Товары — через админку

1. Откройте https://admin-staging.enkaelectronics.com.ge/ — это рабочая админка, несмотря на слово staging в адресе.
2. Откройте нужный товар и вкладку перевода RU или EN. Переведите название, описание, подробное описание, гарантию и значения характеристик. Бренды, модели, SKU и числовые характеристики сохраняйте.
3. Названия характеристик (например, «Мощность») редактируются в общем словаре характеристик: такой перевод используется во всех товарах с этим названием.
4. Проверьте перевод и отметьте его как проверенный. Сохраните черновик, откройте просмотр изменений, затем опубликуйте.
5. После изменения описаний и страниц запустите привычную ручную сборку магазина. Цена и наличие обновляются из API, а HTML и сохранённый текст страницы обновляются при сборке.

Подтверждённый перевод из админки имеет приоритет над первоначальным словарём сайта. Если вы изменили грузинский исходник, старое подтверждение сбрасывается: обновите и снова проверьте соответствующий перевод. Если новый исходник ещё не переведён, показывается грузинский оригинал.

### Подготовленные переводы всех 76 товаров

Файл `admin/translations/ru-en.json` содержит черновики RU/EN названий, описаний, гарантии и характеристик, а также общий словарь 159 названий характеристик. Скачайте файл из репозитория, в новой версии админки нажмите **Импорт** и выберите его. Это специальный пакет переводов: он добавляет только переводы с совпадающим исходником, сохраняет товары, цены и фото, не заменяет уже подтверждённые переводы. После импорта сохраните черновик и проверьте переводы перед публикацией.

Поддержка такого пакета добавлена в код админки в этом изменении. Если рабочая админка ещё показывает старое предупреждение о замене всего каталога, сначала нужно развернуть новую версию Worker админки с production-конфигом `admin/wrangler.production.local.jsonc`. Тестовый `admin/wrangler.local.jsonc` для этого не подходит. Сам файл пакета не публикует ничего автоматически.

## Меню, формы, категории, информационные страницы и сообщения

Все сохранённые переводы находятся в **`assets/i18n/translations.json`**. Их можно менять в редакторе файлов или через GitHub → файл → Edit.

Пример записи:

```json
"გარანტია და დაბრუნება": {
  "ru": "Гарантия и возврат",
  "en": "Warranty and returns"
}
```

Слева — точный грузинский исходник. В `ru` и `en` — тексты, которые увидит посетитель. Чтобы исправить существующий перевод, меняйте только нужное значение `ru` или `en`. Сохраняйте кавычки, запятые и корректный JSON. Ссылки, номера телефонов, модели и числа не меняйте при переводе.

Информационные страницы «О нас», «Контакты», «Доставка», «Гарантия» и «Конфиденциальность» используют тот же словарь. Их перевод пока редактируется в этом файле, а не в товарном редакторе админки. Админка управляет переводами товаров и характеристик.

Если добавляете новый текст или меняете грузинский оригинал в HTML/JS, добавьте для нового точного исходника запись с обоими переводами. Старый ключ не соответствует новому тексту автоматически. Для текста со ссылкой каждая часть до ссылки, сама ссылка и часть после неё имеют отдельные записи.

После правки: сохраните файл → commit → push → запустите привычную ручную сборку для Cloudflare. Обычный push запускает GitHub Pages, а Cloudflare в текущем workflow обновляется через **Actions → Build and Deploy → Run workflow**.

Команда `node scripts/build-localizations.cjs` проверяет JSON и создаёт `assets/i18n/data.js`; этот служебный JS не нужно редактировать. Основной генератор страниц тоже запускает её автоматически. После сборки `node scripts/check-translations.cjs` проверяет RU/EN покрытие всех HTML-страниц и пакета товаров. `node --test tests/*.test.cjs admin/tests/*.test.mjs` проверяет поведение магазина и админки.

## Форма возврата

Скачиваемые заявления переведены отдельно:

- `assets/documents/withdrawal-form.txt` — грузинский;
- `assets/documents/withdrawal-form.ru.txt` — русский;
- `assets/documents/withdrawal-form.en.txt` — английский.

При выборе RU/EN ссылка скачивает соответствующую версию. Если меняете форму, обновляйте все три файла и запускайте сборку.

Переводы подготовлены с машинной основой, затем исправлены основные термины и формулировки. Перед изменением юридического смысла условий сначала обновляйте грузинский оригинал и согласованно правьте оба перевода.
