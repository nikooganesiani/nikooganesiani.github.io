# ENKA Electronics

Статический магазин на Jekyll с Tailwind CSS. Основная локализация — грузинская.

## Сборка и проверка

Нужны Node.js 22.13+, pnpm 11.25.0, Ruby 4.0.6 и Bundler из `Gemfile.lock`.

```sh
pnpm install --frozen-lockfile
bundle install
pnpm check
pnpm build
pnpm check:site
pnpm preview
```

Предпросмотр: `http://127.0.0.1:4173`. Результат сборки находится в `_site/`.
GitHub Actions выполняет полную сборку и проверки перед публикацией. Pull request запускает проверки без публикации. Push в `main`/`master` публикует GitHub Pages; ручной запуск также публикует Cloudflare Pages.

## Главная страница

- `_data/promo_stories.yml` — полезные ссылки и социальные сети.
- `_data/promo_block.yml` — заголовки предложений и `product_id` из каталога. Изображение, название, цена и старая цена берутся из товара, а не из рекламного изображения.
- `_data/catalog.yml` — категории и подкатегории.
- `_data/popular_items.yml` — порядок популярных товаров.
- `generate_pages.js` — получает публичный каталог, проверяет данные и создаёт `_products/`. Пустой или некорректный каталог останавливает сборку.
- `assets/js/global/catalog.js` — один общий запрос каталога для главной, поиска и избранного, тайм-аут и кэш на 5 минут. Популярные товары и предложения также присутствуют в готовом HTML.

Недоступность браузерного хранилища не мешает загрузке страницы и подтверждению принятого заказа. Избранное и история просмотров сохраняются только на устройстве посетителя.

## Изолированная проверка заказов

Сохраните публичный каталог в `.local/catalog.json`, выполните сборку и запустите:

```sh
node scripts/preview.cjs --mock-services
```

Этот режим подменяет каталог, отправку заказа и отслеживание локальными обработчиками и отключает аналитику. Реальные заказы не отправляются. Номер `555000000` имитирует ошибку сервера; другие корректные номера имитируют успех. Для проверки недоступного каталога добавьте `--catalog-error` и откройте новый origin/порт без кэша каталога.

`pnpm check` проверяет валидацию данных, генерацию страниц, обработку сбоев, защиту заказов и безопасность HTML. `pnpm check:site` проверяет главную и все страницы товаров: локальные ссылки, метаданные, Product JSON-LD, наличие, поля формы, отсутствие повторных скриптов/ID и служебных файлов в публикации.

## Общие компоненты

Футер подключается из `_includes/footer.html` и оформляется в `assets/css/components/footer.css`. Карточки создаёт один `assets/js/product/card.js`; серверный вариант `_includes/homepage/product-card.html` использует те же классы и `assets/css/components/product-card.css`. Размещение карточек в сетках и каруселях задаётся контейнерами; внешний вид карточки от страницы не зависит.

Хлебные крошки товара, категории и поиска используют `_includes/breadcrumbs.html`, `_includes/breadcrumb-item.html` и `assets/css/components/breadcrumbs.css`. Категория обновляет только пункты через `assets/js/global/breadcrumbs.js`, клонируя общий шаблон и иконки. Все CSS-файлы общих компонентов импортируются в `assets/css/input.css` и собираются в общий `style.css`. В `assets/css/product.css` остаётся оформление самой страницы товара; переопределения общих компонентов через класс страницы не добавляются.

## Страница товара

Цена, наличие, галерея, характеристики, форма и рекомендации присутствуют в готовом HTML. Общий каталог обновляет цену и наличие одновременно в форме, мобильной панели и структурированных данных. При недоступности каталога остаются данные сборки, сообщение о необходимости подтверждения оператором и кнопка повторной загрузки. Удалённый из доступного каталога товар нельзя заказать. Отсутствующий товар, «скоро» и неизвестные статусы показывают ссылку на альтернативы вместо формы.

Заказ подтверждается только после успешного ответа обработчика. Ошибки сети, HTTP и явные ошибки JSON сохраняют введённые данные и позволяют повторить отправку; ожидание ограничено 20 секундами. Прямой и быстрый заказ используют ID товара из каталога, общую защиту от дублей и блокировку параллельной отправки. Аналитика и доступность хранилища не влияют на подтверждение принятого заказа. При отключённом JavaScript доступен заказ по телефону.

Для проверки изменившейся цены, наличия или удалённого товара можно передать локальный каталог: `node scripts/preview.cjs --mock-services --catalog-file .local/catalog-edge.json`. Все сервисы в этом режиме локальные. Галерея поддерживает свайп, кнопки, стрелки клавиатуры, Home/End и увеличение; Escape закрывает окно и возвращает фокус. Видеоплеер загружается с YouTube только после нажатия.
